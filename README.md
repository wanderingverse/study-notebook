## 🚀 如何使用

如果你想要在本地查看本仓库的笔记或内容：

1. **克隆仓库到本地**
   ```bash
   git clone https://github.com/wanderingverse/study-notebook.git
   cd study-notebook  
   ```

2. **本地浏览**：推荐使用 [Obsidian](https://obsidian.md/) 或其他 Markdown 编辑器打开 `学习` 或 `成长` 目录，以获得最佳阅读体验。
