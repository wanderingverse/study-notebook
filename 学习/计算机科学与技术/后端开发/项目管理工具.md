## 未分类
`<scope>作用域</scope>`：指定依赖的作用范围。
- compile：默认作用域。指示依赖在**编译**、**测试**、**运行**、**打包**时都需要。
- provided：指示依赖在**编译**、**测试**时需要，但运行和打包时不需要。
- runtime：指示依赖在**测试**、**运行**、**打包**时需要，但编译时不需要。
- test：指示依赖在**测试**时需要，但编译、运行、打包时不需要。

## 安装和配置
1. 下载 [gradle-version-bin.zip](https://services.gradle.org/distributions/) 文件后解压，得到 gradle-version 工具包。
2. 【可选】配置 gradle 环境变量。
	1. 新建环境变量：GRADLE_HOME，值为 gradle 工具包根目录路径。
	2. 新建 path 环境变量条目：`%GRADLE_HOME%\bin`
3. 验证 gradle：终端输入：`gradle -v`
## 创建 gradle 项目
使用 `IntelliJ IDEA` 创建。
指定使用项目自带的 Gradle Wrapper 或使用本地已安装的 Gradle。
指定使用 `groovy` 作为 `Gradle` 的构建脚本使用语言。
## groovy 常用语法
- 终端输出：`println("字符串")`
- 定义变量：`def 变量名 = 值`
- 集合操作
	- 定义集合：`def list = [a,b,c]`
	- 向集合添加元素：`list << d`
	- 获取集合中指定下标的元素：`list.get(下标)`
- 字典操作
	- 定义字典：`def map = ["key1" : value1 , "key2" : value2……]`
	- 添加一组键值：`map."key" = value`
	- 获取指定键的值：`value = map.get("key")`
- 定义 closure（闭包）：`def 变量名 = {参数名 -> 语句}`
	- 在闭包中字符串内引用参数：`"${参数名}"`
	- 调用闭包：`闭包变量名(参数)`
- 定义方法：`def 方法名(参数类型 参数名)`
- 调用方法：`方法名(参数)`
## gradle 目录结构
- `src` 目录：同 `maven`
	- src/main/webapp 目录：放置前端文件，如 `html`、`css`、`js` 文件等。
- `build.gradle` 文件：管理 `Java` 项目所需的依赖。
	- `repositories`：管理依赖使用的仓库信息。
		- mavenLocal()：表示依赖从本地仓库获取。
		- `mavenCentral()`：表示依赖从中央仓库获取。
	- `dependencies`：管理 gradle 工程引入的依赖坐标。
		- 依赖作用域：
			- `testCompile`：标识此依赖只在测试阶段导入。
		- 每个依赖坐标有三个元素：
			- `group`：依赖组织名
			- `name`：依赖名
			- `version`：依赖版本
