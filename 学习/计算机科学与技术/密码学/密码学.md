# 应用场景
## 登录认证
web 业务的登录认证场景下，接口调用时推荐使用**非对称加密**算法。
### 原理
- 客户端使用**公钥加密**登录时密码能避免直接暴露密钥。若使用对称加密，客户端或可被窃取密钥。
- 后端使用**私钥解密**密码，得到明文。
### 实现
1. 后端生成一对密钥：公钥+私钥。
2. 前端请求后端公钥。
3. 登录认证时，前端使用公钥加密用户输入的密码，然后将密文提交到后端。
4. 后端接收到密文，使用私钥解密出明文，然后校验登录人信息。
