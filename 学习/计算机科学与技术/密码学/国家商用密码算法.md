# 算法
## SM2
非对称加密算法，基于椭圆曲线密码的公钥密码算法标准。
## SM3
Hash 算法。
## SM4
分组对称加密算法。
## SM9
基于标识的非对称加密算法。
# 实现
## sm-crypto
[sm-crypto](https://github.com/JuneAndGreen/sm-crypto)
国密算法 js 版。
## gmhelper
[gmhelper](https://github.com/ZZMarquis/gmhelper)
基于 Bouncy Castle 库的国密 SM2/SM3/SM4 算法简单封装。
## Bouncy Castle
一个强大的加密库，广泛用于 Java 和 .NET 平台，支持众多加密标准。
