# MCP 简介
Agent 核心构成三要素：LLM、Prompt、Tools。
- Agent：一种基于 LLM 的自治程序，能够理解目标、规划步骤、调用工具并执行任务。
- LLM：Large Language Model，大语言模型。提供基础的“智能”和“推理”能力，负责理解输入、生成输出、维持上下文。
- Prompt：提示词/上下文约束。约束 LLM 的行为，定义 Agent 的角色、目标、边界。
- Tools：工具或外部能力。让 Agent 能超越纯文本输出，而执行各种任务。如调用数据库、API、搜索引擎、代码执行环境等。
