# 概念和术语
- 大盘：指上证指数。由上海证券交易所上市的所有公司组成的一个指数。该指数一定程度上能够反映股市整体的涨跌情况。
- 白马股：长期绩优、回报率高、投资价值较高的股票。
	- 医药、消费、科技、金融四个领域最容易出现长线白马股。
- 蓝筹股：指长期稳定增长的、大型的传统工业股及金融股。
- 成长股：指发行股票时规模并不大，但公司的业务蒸蒸日上，管理良好、利润丰厚，产品在市场上有竞争力的公司的股票。
- 利好：对股价上涨可能有利的信息。
- 利空：可能导致股价下跌的信息。
- 崩盘：描述证券接连不断大量抛出，证券市场价格无限度下跌，即卖盘大量涌现的情形。
- 踏空：描述股价上涨时未能及时买入，因而未能因此赚钱的情形。
- 跳水：描述股价迅速下滑，下滑幅度很大的情形。
